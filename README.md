# International Conference on Rural Transformation in the Global Context (ICRTGC 2027)

> **Theme:** Strategies for Resilience and Sustainability (Hybrid Mode)  
> **Dates:** 3 – 5 February 2027  
> **Organized by:** School of Management Studies, The Gandhigram Rural Institute (Deemed to be University), Dindigul, Tamil Nadu, India.  
> **Accreditation:** NAAC Accredited with 'A++' Grade (4th Cycle, 2025)

---

## 🌾 Concept: "Roots to Routes"

This website embodies the **"Roots to Routes"** creative philosophy:
1. **Soil (Roots):** Grounded in Mahatma Gandhi’s revolutionary philosophy of *Nai Talim* (value-based experiential education), cooperative risk-pooling, and indigenous knowledge.
2. **Sprout (Growth):** Nurturing rural livelihoods, rural MSMEs, agro-processing, and green value chains.
3. **Canopy (Resilience):** Climate-smart agriculture, decentralized renewable energy, and community watershed governance.
4. **Network (Routes):** Transforming leaf veins into digital connections through Digital Public Infrastructure (DPI), AI/IoT in cooperatives, and global policy frameworks.

## 🎨 Design System & Heritage Motifs

- **Twin Pillars:** Intertwined vines of **Resilience** (`#C4622D` Terracotta) and **Sustainability** (`#2F7D4F` Paddy Green).
- **Kolam / Rangoli Art:** Symmetrical Tamil Nadu floor patterns woven into dividers, borders, and intro loader.
- **Gandhigram Charkha:** Rotating spinning wheel emblem used as the loader, section badge, and interactive scroll progress indicator.
- **Khadi Texture:** Subtle handloom cloth grain overlay on warm cream surfaces.
- **Five Track Colors:**
  - Track I (Cooperatives): `#C4622D` (Terracotta)
  - Track II (Macro-economy): `#F2A900` (Marigold)
  - Track III (MSMEs): `#2B3A67` (Indigo)
  - Track IV (Climate Adaptation): `#2F7D4F` (Paddy Green)
  - Track V (Digital Transformation): `#1FA3A3` (Teal-Cyan)
- **Dusk / Dawn Theme Toggle:** Sun/Moon toggle with full dark mode support.

## 🚀 Key Interactive Features

1. **Live Countdown:** Real-time countdown clock to 3 February 2027 conference inauguration.
2. **Interactive Fee Calculator:** Instant dynamic fee calculation based on Mode (Offline vs Online) × Category (Student, Scholar, Faculty, Leader) × Residency (GRI, Indian, Foreign) with currency switcher (₹ / $).
3. **Abstract Submission Portal:**
   - Real-time word counter with strict 500-word limit validation.
   - Dynamic repeatable co-author fields.
   - Unique Reference ID generator (`ICRT27-S-XXXX`) with confetti celebratory effect.
4. **Calendar Download (.ics):** 1-click addition of conference dates directly to Google Calendar, Apple Calendar, or Outlook.
5. **Direct Tap-to-Call & WhatsApp Support:** Help desks for Registration, Submissions, and Accommodation with phone and WhatsApp links.
6. **Admin Dashboard MVP:** Filter submissions by track, search records, view inquiries, and export data directly to CSV.

## 🛠️ Tech Stack & Scripts

- **Framework:** Next.js 14 (App Router) + TypeScript
- **Styling:** Tailwind CSS + CSS Variables for heritage color tokens
- **Icons:** Custom SVG line icons (Cooperatives, Macroeconomics, Handloom/Charkha, Climate Sapling, Digital Tree) + Lucide React
- **Animations:** Framer Motion, CSS Keyframes, Canvas Confetti

### Getting Started

```bash
# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Visit `http://localhost:3000` to view the website.
